# Codename Generator

A static 120-cycle project codename generator using the approved adjective and noun roots.

## Local check

```bash
npm test
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Deployment

Every push to `main` runs the GitHub Pages workflow. The published site is expected at:

`https://learning.github.io/codename-generator/`
